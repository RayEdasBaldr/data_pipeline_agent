构建一个跨软件数据搬运与报表生成 Agent，核心解决财务与运营人员每日在 Excel、邮件客户端、OA 系统及 ERP 桌面软件间手动复制粘贴数据的痛点。

核心逻辑流采用长链推理 + 多 Agent 协作：

感知层 Agent：定时轮询指定邮箱收件箱和本地文件夹，识别附件中的日报/周报 Excel，并提取邮件正文中的非结构化备注信息。

规划层（长链推理）：接收用户自然语言指令（如“将销售表里‘已回款’且金额>1万的行，录入财务系统的月度台账”），自动拆解为：打开Excel并筛选 → 提取关键字段 → 唤起 ERP 窗口 → 定位录入表单 → 逐行提交 → 保存并生成日志。

GUI 控制 Agent：基于 pyautogui + uiautomation 对 Windows 桌面软件（金蝶、用友、SAP）进行无侵入式自动化点击和输入，无需改造原有系统。

验证 Agent：每次录入后截取关键界面区域，与预期状态进行像素级/文本比对，确认保存成功；失败则自动重试 3 次并告警。
